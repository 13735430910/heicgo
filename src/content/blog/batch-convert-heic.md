Converting one HEIC file is easy — but what about 50, 200, or 1000 photos? Here's how to batch convert HEIC to JPG efficiently.

## Method 1: heicgo.com (Free, No Upload)

1. Go to [heicgo.com](/)
2. Drag and drop ALL your HEIC files at once
3. Adjust quality settings
4. Click "Convert to JPG"
5. Click "Download All (ZIP)" to get a single ZIP archive

Benefits: No file upload, preserves EXIF, free with no limits.

## Batch Conversion with Preview on Mac

1. Select all HEIC files in Finder
2. Open with Preview
3. Select all in sidebar (Cmd+A)
4. File → Export Selected Images
5. Choose JPEG format and destination

Limitation: No EXIF preservation, slower for large batches.

## Using Shortcuts on iPhone

1. Open Shortcuts app
2. Create a new shortcut:
   - "Select Photos" (allow multiple)
   - "Convert Image" (to JPEG)
   - "Save to Photos"
3. Run the shortcut — select all HEIC photos

This method works but may reduce quality and strips EXIF.

## Batch Size Recommendations

| Number of Files | Recommended Tool | Estimated Time |
|----------------|-----------------|---------------|
| 1-10 | Any method | < 1 minute |
| 10-100 | heicgo.com | 1-5 minutes |
| 100-500 | heicgo.com | 5-15 minutes |
| 500+ | Desktop software | 15-60 minutes |

For very large batches (1000+), split into groups of 100-200 to avoid browser memory limits.

## Preserving EXIF in Batch Mode

Most batch converters strip EXIF. heicgo preserves GPS, timestamps, and camera info for every file in the batch — no other free tool does this.
