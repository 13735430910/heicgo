Most guides tell you to convert HEIC to JPEG. But sometimes PNG is the better choice.

## JPEG vs PNG: The Tradeoff

| Factor | JPEG | PNG |
|--------|------|-----|
| Compression | Lossy | Lossless |
| File size (photo) | 2-8 MB | 20-40 MB |
| Transparency | No | Yes (alpha channel) |
| Bit depth | 8-bit | Up to 16-bit |
| Text/graphics | Compression artifacts | Perfect sharpness |

## When to Convert HEIC to PNG

**Good reasons to choose PNG:**

1. **Screenshots with text** — JPEG smears text edges; PNG keeps them crisp
2. **Images requiring editing** — lossless format preserves all data for further editing
3. **Need transparency** — logos, overlays, and graphics over backgrounds
4. **Medical/technical images** — where compression artifacts could obscure details
5. **Printing at large sizes** — lossless format preferred for fine art prints

**Bad reasons to choose PNG:**
- "PNG is higher quality" (for photos, the 5× file size isn't worth the imperceptible difference)
- Web display of photographs (JPEG or WebP is far more efficient)

## File Size Reality Check

Converting a 12 MP iPhone photo:

| Format | File Size | Emailable? | Printable? |
|--------|-----------|:--:|:--:|
| HEIC (original) | 2.4 MB | Yes | Yes (up to 16×20) |
| JPEG (92% quality) | 4.8 MB | Yes | Yes |
| JPEG (100% quality) | 8 MB | Maybe | Yes |
| PNG (lossless) | 28 MB | No | Yes |

## The Bottom Line

**Convert HEIC → JPEG** for 95% of use cases. The small quality difference at 92%+ is invisible, and the 5-6× smaller file size saves storage and bandwidth.

**Convert HEIC → PNG** only when you specifically need lossless quality, transparency, or are working with text-heavy screenshots.
