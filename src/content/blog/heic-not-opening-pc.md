Downloaded iPhone photos to your PC but HEIC files won't open? Here are five fixes, ranked from simplest to most involved.

## 1. Install HEIF Image Extensions (Free)

The most common fix:

1. Open Microsoft Store
2. Search "HEIF Image Extensions"
3. Install the free extension
4. Restart your PC

If already installed, try uninstalling and reinstalling — sometimes updates break compatibility.

## 2. Update Windows

Older Windows 10 builds lack HEIC support:

1. Settings → Windows Update
2. Check for updates
3. Install all pending updates
4. Restart

Windows 10 version 1903+ and all Windows 11 versions include HEIC support.

## 3. Use a Free Online Converter

If the codec still doesn't work, skip the Windows viewer entirely:

1. Go to [heicgo.com](/)
2. Drag in your HEIC files
3. Convert to JPEG
4. Windows opens JPEG natively

This is faster than troubleshooting codec issues and preserves EXIF metadata.

## 4. Check File Corruption

Sometimes the file itself is the problem:

- Verify the file extension is `.heic` or `.heif` (not renamed accidentally)
- Check file size — 0 KB or very small files may be corrupted
- Try opening the original file on the iPhone to confirm it works
- Re-transfer the file from iPhone to PC

## 5. Update Graphics Driver

HEIC decoding uses hardware acceleration:

1. Device Manager → Display adapters
2. Right-click → Update driver
3. Search automatically
4. Restart

This is a rare cause but worth checking if other methods fail.

## Prevention: Stop Taking HEIC Photos

On iPhone: Settings → Camera → Formats → "Most Compatible"

This makes all future photos JPEG — no conversion needed.
