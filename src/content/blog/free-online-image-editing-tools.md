You don't need Photoshop for basic image editing. These free browser-based tools handle cropping, resizing, format conversion, and more.

## 1. heicgo.com — HEIC Conversion + Compression

**Best for:** Converting iPhone photos to universally compatible JPEG

[heicgo.com](/) excels at one thing: converting HEIC to JPEG with EXIF preservation. Key features:

- Client-side processing (no upload)
- Batch conversion with ZIP download
- Quality slider (10-100%)
- GPS and camera metadata preserved
- Works on all modern browsers

**Limitation:** Purpose-built for HEIC conversion, not a general editor.

## 2. Photopea — Free In-Browser Photoshop

**Best for:** Full-featured photo editing

[Photopea.com](https://www.photopea.com) is a near-perfect Photoshop clone that runs in your browser. It supports:

- PSD, Sketch, XD, and RAW file formats
- Layers, masks, blending modes
- Adjustment layers and filters
- Export to JPEG, PNG, WebP, SVG

**Limitation:** Ad-supported. Heavier on system resources.

## 3. Squoosh — Google's Image Optimizer

**Best for:** Compression and format comparison

[Squoosh.app](https://squoosh.app) by Google Chrome team lets you:

- Compare original vs compressed side-by-side
- Adjust quality with live preview
- Resize, reduce palette, convert formats
- Works offline after first visit (PWA)

**Limitation:** Single-image workflow, no batch processing.

## 4. Remove.bg — Background Removal

**Best for:** One-click background removal

[Remove.bg](https://www.remove.bg) uses AI to remove backgrounds:

- Works on portraits, products, objects
- Free tier: up to 50 images/month
- Download as PNG with transparency

**Limitation:** Limited free credits. Requires upload to their servers.

## 5. Canva — Design + Basic Editing

**Best for:** Social media graphics and marketing materials

[Canva.com](https://www.canva.com) combines photo editing with design templates:

- Crop, filter, adjust photos
- Add text, shapes, and elements
- Thousands of templates
- Direct export for social media

**Limitation:** Many premium features require Pro subscription ($12.99/month).

## Quick Reference

| Tool | Best For | Privacy | Free Tier |
|------|----------|:---:|:---:|
| heicgo.com | HEIC → JPEG | Local processing | Unlimited |
| Photopea | Advanced editing | Local processing | Ad-supported |
| Squoosh | Compression | Local processing | Unlimited |
| Remove.bg | Background removal | Server upload | 50/month |
| Canva | Design + social | Server upload | Limited |

For most photo needs, start with heicgo (format conversion) and Photopea (editing) — both process files locally without uploading to servers.
