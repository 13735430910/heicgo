Windows doesn't natively support HEIC files. When you transfer photos from iPhone to PC, you'll see `.heic` files that won't open. Here are three free solutions.

## Method 1: heicgo.com (Recommended)

Go to [heicgo.com](/) and drag in your HEIC files. Convert them to JPEG instantly — no software install, no upload, and EXIF data is preserved.

## Method 2: Microsoft HEIC Codec (Free)

Microsoft offers a free HEIF Image Extension in the Store:

1. Open the Microsoft Store
2. Search for "HEIF Image Extensions"
3. Click Install
4. After installation, HEIC files should open in Photos app

Note: This only enables viewing — to edit or convert, you'll need Method 1 or 3.

## Method 3: CopyTrans HEIC (Free)

CopyTrans HEIC for Windows is a free tool that integrates with Windows Explorer:

1. Download from copytrans.net
2. Install and restart Explorer
3. HEIC thumbnails now show in File Explorer
4. Right-click any HEIC → "Convert to JPEG"

## Why Photos Look Dark on Windows

If your HEIC photos appear dark or washed out, it's a color profile issue. Windows uses a different HDR tone mapping than iOS. Converting to JPEG with heicgo preserves the correct color profile.

## FAQ

**Is the Microsoft codec really free?** The basic extension is free. There's a paid HEVC Video Extensions ($0.99) for video support, but the image codec is free.

**Can I batch convert?** Yes — heicgo supports dragging multiple files at once.
